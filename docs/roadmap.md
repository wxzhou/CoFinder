# CoFinder Roadmap

## V1 (current)

- Local file browsing
- SFTP remote browsing
- Tab isolation
- Site Manager + saved profiles
- safeStorage credential support
- rsync upload/download queue
- Multi-select + basic context menu

## V1.1 (planned)

- Delete / rename actions
- Remote edit auto-sync
- Quick Look for remote files
- Drag selection
- Drag-and-drop upload/download
- Preferences
- Full i18n
- Column resize / reorder

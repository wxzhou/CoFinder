# CoFinder V2.9 / v1.9.0 Release Plan

| Field | Value |
| --- | --- |
| Product milestone | V2.9 release rollup |
| Target release | v1.9.0 |
| Status | Release candidate |

## Goal

Publish a stable macOS build after the v1.8.0 release, rolling up the hands-on bug fixes and polish completed through the V2.8.1-V2.8.9 patch line.

## Scope

- Bump package and documentation version references to v1.9.0.
- Keep the current feature set stable; no new feature development in this release-prep milestone.
- Build fresh `CoFinder-1.9.0-arm64.dmg` and `.zip` artifacts.
- Prepare GitHub release notes covering all user-visible changes since v1.8.0.
- State unsigned/local-build distribution status honestly.

## Non-Goals

- No remote copy/move.
- No grep/less content tools.
- No multi-lane parallel Jobs implementation.
- No remote gzip percentage progress.
- No new UI redesign.

## Acceptance

- `package.json`, `package-lock.json`, README, changelog, roadmap, and this release plan identify v1.9.0 as the release target.
- `npm run typecheck`, `npm test`, `npm run build`, `npm run check:secrets`, `npm run package`, and `npm run dist` pass.
- `release/CoFinder-1.9.0-arm64.dmg` and `release/CoFinder-1.9.0-arm64.zip` exist.
- The packaged app launches and loads the V12 shell from `file://`.
- Release notes cover changes since v1.8.0.

## Smoke Focus

- Launch packaged app from `release/mac-arm64/CoFinder.app`.
- Confirm local browsing and the V12 shell load.
- Confirm Change Timestamp dialog fields stay inside the modal.
- Confirm Jobs pane and File Operation submenu are present.
- If time permits, repeat remote login plus a small upload/download under the isolated remote test root.

# V2.8 Decision Review

Chosen track: **Track B — Remote Quick Look**.

Reasons:

- CoFinder already has a safe read-only remote preview cache for sniffed text/images.
- Users benefit from pressing Space to inspect remote files without entering the write-capable Edit workflow.
- Real Column View was explicitly deferred in V2.7 because it needs a larger navigation model.
- Recursive remote search remains risky on shared servers unless it is capped and user-triggered.

V2.8 implementation scope:

- Space on a single selected remote file opens the read-only remote preview path.
- Remote context menu exposes **Quick Look** separately from **Open** and **Edit**.
- Text/images only; unsupported files show a clear message.
- Existing remote preview cache lifecycle and read-only behavior remain unchanged.

Moved to future roadmap:

- Track A — Real Column View.
- Track C — Recursive/bounded remote search.

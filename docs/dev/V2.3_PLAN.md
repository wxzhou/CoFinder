## Goal

Fix three v1.2.0 usability regressions without changing CoFinder's core file-management model.

## Scope / Milestones

### M1 — Text Editor Preference UI

**Status:** Implemented.

- Replace the datalist-only text editor field with an explicit selector.
- Include `system`, `TextEdit`, `TextMate`, and a `Custom...` mode.
- Preserve support for custom application names or `.app` paths.

**Acceptance checks**

- Preferences visibly offers TextEdit and TextMate as selectable options.
- Existing custom editor values continue to display and save.
- Remote text preview still uses the stored setting.

### M2 — Copy Current Path Shortcut Reliability

**Status:** Implemented.

- Keep the advertised `Cmd+Option+C` binding.
- Detect the physical `C` key (`event.code === "KeyC"`) so Option-modified text does not break the shortcut.
- Preserve `Cmd+Shift+C` for selected path copy.

**Acceptance checks**

- `Cmd+Option+C` copies the active pane current path.
- `Cmd+Shift+C` still copies selected full paths.
- Editable text fields do not get intercepted.

### M3 — Breadcrumb / Address Bar Integration

- V12 panes show breadcrumb only by default.
- Clicking breadcrumb empty space, double-clicking breadcrumb, or pressing `Cmd+L` switches the active pane breadcrumb to a full path input.
- Enter navigates to the typed path.
- Escape or blur exits edit mode and restores the current path text.
- Recent, History, Filter names, and Clear Recent remain in the navigation row without a second path input.
- Provide Copy path from the breadcrumb area context menu or button.

**Acceptance checks**

- No separate V12 full-path input is visible beside breadcrumb in normal mode.
- Local and remote `Cmd+L` path entry works.
- Local and remote breadcrumb empty click / double-click path entry works.
- Copy path from the breadcrumb area copies the pane current path.

## Test Strategy

- Unit or type-level validation where practical for changed helper code.
- Full regression gates: `npm test`, `npm run typecheck`, `npm run build`.
- Manual smoke:
  - Preferences text editor selector shows TextEdit/TextMate/custom.
  - `Cmd+Option+C` copies active local and remote paths.
  - Breadcrumb path edit Enter/Escape/blur behavior works for local and remote panes.

## Risk Notes

- Path edit mode must not interfere with breadcrumb segment clicks.
- Remote path edit must remain disabled/disconnected-safe.
- The legacy UI can keep its older path input behavior; this milestone targets V12.

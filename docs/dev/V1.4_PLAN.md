# CoFinder V1.4 Plan — Transfer Safety & Conflict Handling

## Metadata

| Field | Value |
| --- | --- |
| **Product milestone** | V1.4 |
| **Target release** | v0.5.0 |
| **Status** | Planned |
| **Depends on** | V1.3 complete or shortcut/splitter/tab work stable enough not to block queue UX |
| **Non-goals** | Drag-and-drop transfer; marquee selection; remote edit auto-sync; **parallel** transfer queue (remain serial unless explicitly replanned) |

## Goal

Make transfers **predictable and trustworthy**, especially when a destination already exists—no silent overwrites or ambiguous behavior.

## Scope / milestones

### M1 — Conflict detection

- **Upload** and **download** paths: detect existing targets before committing.
- Handle **files** vs **directories** distinctly.
- Cover both **local** and **remote** destinations.
- Detection and policy decisions run in **main/service** layer; renderer **displays** choices and **initiates** user-selected resolution only through existing IPC patterns.

### M2 — Conflict resolution dialog

- Support: **Overwrite**, **Skip**, **Rename / Keep both**, **Cancel**, **Apply to all** (where safe).

### M3 — Transfer task state refinement

- Normalize or extend states toward: **waiting**, **checking**, **conflict**, **transferring**, **completed**, **failed**, **canceled** (map to existing enums where possible; document transitions).

### M4 — Retry failed transfer

- Per-task **retry**; **retry all failed**.
- Retry preserves **source**, **target**, **direction**, **tabId**, and **profile/connection** semantics.

### M5 — Error taxonomy

- Clearly distinguish at least: **rsync not found**, **ssh BatchMode failed**, **permission denied**, **path not found**, **no space left**, **remote disconnected**, **unknown error** (stable codes/messages for renderer).

### M6 — Queue UI polish

- Clearer per-item status; **copy error detail** for failed items.
- Optional grouping/filtering for completed/failed/active—keep complexity bounded.

## Risk notes

- **Never** pass SFTP-saved passwords into **rsync** or shell commands.
- **Renderer must not** own overwrite/security policy—only main/service.
- Conflict flows must **preserve global serial queue** invariants (no re-entrancy bugs).
- User choices for “apply to all” must be **scoped** safely (e.g. per batch/session) to avoid destructive surprises.

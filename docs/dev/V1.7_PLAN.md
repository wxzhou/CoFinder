## Goal

Improve browsing efficiency in **large directories** and when jumping between locations—without building a search engine.

## Scope / milestones

### M1 — Quick filter in current directory

- Filter **current listing** by name (substring; optional light fuzzy—keep deterministic).
- Both **local** and **remote** panes.
- **Not** a global indexed search.

**Status:** Implemented as deterministic case-insensitive substring filtering of the already-loaded listing.

### M2 — Path autocomplete

- **Local** path bar autocomplete.
- **Remote** path bar: lightweight autocomplete based on connection + **already visited** paths (avoid spamming SFTP).

**Status:** Implemented with HTML datalist suggestions from current path, current tab history, favorites, and recents. Remote suggestions do not trigger SFTP traffic.

### M3 — Recent locations

- **Local** recent paths.
- **Remote** recent paths **per profile**.
- Distinct from **favorites**; user can **clear** history.

**Status:** Implemented in renderer localStorage as non-secret local recents and per-profile remote recents. Clear buttons are provided.

### M4 — History UI

- Back / forward **dropdown** or richer history affordance per pane.
- Per-pane history; **tab isolation** preserved.

**Status:** Implemented as per-pane history dropdowns using existing tab-local history stacks.

### M5 — Bookmark model cleanup

- Clarify boundaries in UI and data: **local favorites**, **remote favorites**, **recent locations**, **Site Manager** profiles—no overlapping semantics or duplicate storage without documentation.

**Status:** Clarified in README, roadmap, architecture/project context, and smoke docs. No new main-process IPC or data file was added.

## Risk notes

- Remote autocomplete/recents must **not** generate excessive **SFTP** traffic.
- Filtering must **not** corrupt **selection** or multi-select semantics (define interaction when filter toggles mid-selection).
- Remote path suggestions must avoid leaking **other tabs’** paths unless product explicitly allows.

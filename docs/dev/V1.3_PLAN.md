# CoFinder V1.3 Plan — Interaction Efficiency & Layout Control

## Metadata

| Field | Value |
| --- | --- |
| **Product milestone** | V1.3 |
| **Target release** | v0.4.0 |
| **Status** | Planned — target **v0.4.0** (not shipped until tagged); repo may use **`package.json` 0.4.0** early for build/dist testing |
| **Depends on** | V1.2 shipped (default V12 shell, local favorites baseline, IPC/contracts stable) |
| **Non-goals** | Transfer conflict handling; drag-and-drop upload/download; marquee selection; full Preferences UI; remote edit auto-sync |

## Goal

Move the V12 shell from visually and functionally usable to **efficient for daily use**: keyboard-driven workflows, resizable panes, ordered tabs, polished favorites (local + per-profile remote).

## Scope / milestones

### M1 — Keyboard shortcuts MVP

- Coverage targets: **Rename**, **Get Info**, **Delete**, **Copy Path**, **Refresh pane**, **New tab**, **Close tab**, **Switch next/previous tab**, **Upload selected**, **Download selected**, **Focus local pane**, **Focus remote pane**, **Open Site Manager**.
- Shortcuts must respect the **active pane** where applicable.
- Upload/download shortcuts must validate **selection**, **target pane**, **remote connection state**, and **paths** before enqueueing.
- Shortcuts must **not** bypass existing confirmations (e.g. delete).
- Must **not** regress **Cmd/Ctrl+A** selection behavior.

### M2 — Pane splitter

- Draggable splitter between **local** and **remote** panes.
- Persist pane width ratio; enforce sensible **minimum widths**.
- **Double-click** splitter resets to **50/50**.
- Must not break **inspector** or **transfer drawer** layout.

### M3 — Tab reorder

- Drag tabs to reorder; **active tab** and per-tab **local/remote state** remain intact.
- **No** cross-window tab tear-off; **no** tab groups.

### M4 — Local favorites polish

- **Add / remove / rename / reorder** local favorites.
- Sensible defaults: **Home**, **Desktop**, **Downloads**, **Documents**.
- **Add Current Local Path to Favorites**.
- Invalid paths show a clear UI state.
- Clicks affect **local pane** only.

### M5 — Remote favorites by profile

- Each **site profile** owns a set of **remote favorites**.
- When the active tab’s connection matches a profile, show that profile’s remote favorites.
- Clicks affect **remote pane** only; **Add Current Remote Path to Favorites**; **rename label / remove**.
- When disconnected, avoid accidental navigation—**disabled** state or explicit messaging.
- **No** cross-profile copy, import/export, or custom icons.

### M6 — Hardening / release

- Shortcut conflict audit (system vs in-app).
- Verify packaged **`file://`** build.
- Documentation and smoke tests updated for new shortcuts and splitter behavior.

## Risk notes

- **Keyboard shortcuts** can conflict with macOS or Electron defaults; need explicit handling and menu/`aria` hints where relevant.
- **Splitter persistence** must not corrupt layout on small windows or future inspector widths.
- **Remote favorites** must stay aligned with **security** rules: no secrets in favorite payloads; respect **tab / connection** isolation.

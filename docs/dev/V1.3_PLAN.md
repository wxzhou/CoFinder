# CoFinder V1.3 Plan — Interaction Efficiency & Layout Control

## Metadata

| Field | Value |
| --- | --- |
| **Product milestone** | V1.3 |
| **Target release** | v0.4.0 |
| **Status** | Implemented in development tree — target **v0.4.0** (not shipped until tagged); repo uses **`package.json` 0.4.0** for build/dist testing |
| **Depends on** | V1.2 shipped (default V12 shell, local favorites baseline, IPC/contracts stable) |
| **Non-goals** | Transfer conflict handling; drag-and-drop upload/download; marquee selection; full Preferences UI; remote edit auto-sync |

## Goal

Move the V12 shell from visually and functionally usable to **efficient for daily use**: keyboard-driven workflows, resizable panes, ordered tabs, polished favorites (local + per-profile remote), and a limited read-only remote preview path for common text/image files.

## Scope / milestones

### M1 — Keyboard shortcuts MVP

- Coverage targets: **Rename**, **Get Info**, **Delete**, **Copy Path**, **Refresh pane**, **New tab**, **Close tab**, **Switch next/previous tab**, **Upload selected**, **Download selected**, **Focus local pane**, **Focus remote pane**, **Open Site Manager**.
- Shortcuts must respect the **active pane** where applicable.
- Upload/download shortcuts must validate **selection**, **target pane**, **remote connection state**, and **paths** before enqueueing.
- Shortcuts must **not** bypass existing confirmations (e.g. delete).
- Must **not** regress **Cmd/Ctrl+A** selection behavior.

**Implemented:** `F2`, Delete/Backspace, `Cmd/Ctrl+I`, `Cmd/Ctrl+Shift+C`, `Cmd/Ctrl+R`, `Cmd/Ctrl+N`, `Cmd/Ctrl+W`, `Cmd/Ctrl+[` / `]`, `Cmd/Ctrl+U`, `Cmd/Ctrl+D`, `Cmd/Ctrl+1`, `Cmd/Ctrl+2`, `Cmd/Ctrl+K`, and Space preview. Editable fields still keep native text behavior.

### M2 — Pane splitter

- Draggable splitter between **local** and **remote** panes.
- Persist pane width ratio; enforce sensible **minimum widths**.
- **Double-click** splitter resets to **50/50**.
- Must not break **inspector** or **transfer drawer** layout.

**Implemented:** V12 pane splitter with local `localStorage` ratio persistence and double-click reset to 50/50.

### M3 — Tab reorder

- Drag tabs to reorder; **active tab** and per-tab **local/remote state** remain intact.
- **No** cross-window tab tear-off; **no** tab groups.

**Implemented:** drag-and-drop reorder in the existing tab strip; active tab id and per-tab local/remote state are preserved.

### M4 — Local favorites polish

- **Add / remove / rename / reorder** local favorites.
- Sensible defaults: **Home**, **Desktop**, **Downloads**, **Documents**.
- **Add Current Local Path to Favorites**.
- Invalid paths show a clear UI state.
- Clicks affect **local pane** only.

**Implemented:** add/remove/rename/reorder custom local favorites, restore defaults, missing-path state, local-only navigation.

### M5 — Remote favorites by profile

- Each **site profile** owns a set of **remote favorites**.
- When the active tab’s connection matches a profile, show that profile’s remote favorites.
- Clicks affect **remote pane** only; **Add Current Remote Path to Favorites**; **rename label / remove**.
- When disconnected, avoid accidental navigation—**disabled** state or explicit messaging.
- **No** cross-profile copy, import/export, or custom icons.

**Implemented:** profile-owned remote favorites with add current remote path, click-to-navigate, rename, remove, and reorder. Payloads contain paths/labels only, no secrets.

### M6 — Limited read-only remote preview cache

- Scope: **view only**, no edit auto-sync and no remote write-back.
- Supported content: text files detected by content sniffing (not extension-only) and common image formats detected by magic bytes.
- Implementation: download the remote file into an app-managed local cache/temp area, then open the local cached copy with the system default app.
- Cache reuse: when opening the same remote file again, compare remote `mtime` and size against cached metadata; re-download only when the remote file changed.
- Cleanup: keep cached files after viewer close; remove cache entries for a tab/connection on disconnect, tab close, and app quit.
- UI entry points: context menu and/or toolbar/inspector may expose **Preview Remote File**. Existing local Quick Look remains unchanged.
- Non-goals: no binary/document preview beyond sniffed text/images; no editor, save-back, remote Quick Look parity, or persistent cache across app restarts.

**Implemented:** `remote:previewOpen`, tab/connection cleanup IPC, content sniffing for text/common images, local cache reuse by remote `mtime` + size, and cleanup on disconnect/tab close/quit.

### M7 — Hardening / release

- Shortcut conflict audit (system vs in-app).
- Verify packaged **`file://`** build.
- Documentation and smoke tests updated for new shortcuts, splitter behavior, favorites, and remote preview cache.

**Implemented in dev tree:** unit/type/build gates are expected before tagging; package verification remains part of release prep.

## Risk notes

- **Keyboard shortcuts** can conflict with macOS or Electron defaults; need explicit handling and menu/`aria` hints where relevant.
- **Splitter persistence** must not corrupt layout on small windows or future inspector widths.
- **Remote favorites** must stay aligned with **security** rules: no secrets in favorite payloads; respect **tab / connection** isolation.
- **Remote preview cache** must stay read-only from CoFinder's perspective; never upload local cached edits back to the server in V1.3.

## Goal

Address the highest-friction issues found while using **CoFinder v1.0.0**: transfer correctness, reliable file operations, cleaner information/path UI, and everyday navigation shortcuts. This is a stabilization and usability release, not a broad redesign.

## Scope / Milestones

### M1 — Transfer Correctness And Unicode Paths

- Investigate and remove the ~10 second delay before transfers actually start.
- Fix directory upload target semantics so uploading `/abc/def/xyz` to `/path1/path2` creates `/path1/path2/xyz`, not `/path1/path2/xyz/xyz`.
- Support Chinese and other Unicode path characters for local and remote rsync transfer paths.
- Preserve existing guardrails against shell/control-character injection; do not loosen host/user validation.

**Acceptance checks**

- Upload and download a small file; task should start promptly without an unexplained fixed delay.
- Upload a folder and verify destination nesting exactly once.
- Upload/download files whose local and remote paths contain Chinese characters.
- Existing transfer conflict policies still work: prompt, overwrite, skip, rename, cancel.
- Unit tests cover rsync path validation and folder target generation.

### M2 — File Operation Reliability

- Fix remote folder deletion.
- Fix local and remote New Folder actions so failures surface as clear UI errors.
- Add local New Folder if the toolbar/context model exposes “New folder” for both panes.
- Add “New Text File” for local and remote panes if it can reuse existing operation boundaries safely.
- Validate names in main process and reject `/`, null bytes, empty names, and control characters.

**Acceptance checks**

- Delete local folder and remote folder in isolated test roots.
- Create local folder and remote folder from toolbar/context menu.
- Create local and remote text file with default unique names such as `Untitled.txt`, `Untitled 2.txt`.
- All create/delete failures return deterministic `{ ok, error }` payloads and visible UI messages.

### M3 — Remote Preview Sniffing Improvements

- Improve text sniffing so common extensionless or domain-specific text files, including `.bed`, open as text when contents are text-like.
- Keep binary files rejected or delegated clearly; do not rely only on file extension.
- Add tests for `.bed`, tab-delimited text, UTF-8 text, and binary-with-NUL rejection.

**Acceptance checks**

- Remote `.bed` file opens with default text editor path, not “choose app” fallback.
- Remote image preview behavior remains unchanged.
- Unsupported binary file still shows a clear unsupported message.

### M4 — Inspector As The Single Info Surface

- Remove the Get Info modal as the default UI.
- Route toolbar `i`, right-click `Get Info`, and `Cmd+I` to show/focus Inspector instead.
- Remove Inspector’s nested `Get Info` action to avoid recursion.
- Move missing detailed fields into Inspector: full path, type, size, modified, permissions, owner, group.
- Add file count and subfolder count for selected directories when cheap; for remote directories, calculate asynchronously and cap traversal.
- Stop auto-opening Inspector on ordinary single-click if it makes the file list jump. Prefer explicit toolbar toggle, `Cmd+I`, or persisted preference.

**Acceptance checks**

- No Get Info modal appears from toolbar, context menu, or shortcut.
- Inspector displays the same core fields previously available in modal.
- Directory counts appear for local and remote directories, with loading/capped states where applicable.
- Selecting files does not unexpectedly squeeze the file list unless Inspector is already open or explicitly requested.

### M5 — Path And Pane Navigation Polish

- Add “restore last local path” and “restore last remote path” behavior in Preferences.
- Remote restore must not silently reconnect with stale credentials; only restore path after user reconnects to the matching profile unless explicit reconnect is later designed.
- Add toolbar Home button for the active pane; remote Home uses SFTP home directory for current connection.
- Add Copy Current Path button and keyboard shortcut.
- Add a stronger active-pane indicator in V12 so users can see where toolbar shortcuts apply.
- Consider unifying breadcrumb and path input so the current path is not displayed twice. Default to breadcrumb; switch to editable path field via click/shortcut.

**Acceptance checks**

- Relaunch restores local path when enabled.
- Reconnecting a saved remote profile can restore last remote path for that profile when enabled.
- Home button works for local and remote panes.
- Copy Current Path copies active pane path without selecting text manually.
- Active pane is visually obvious in both light and dark-ish system appearances.

### M6 — macOS And Layout Integration

- Add Preferences to the macOS application menu using Electron menu integration.
- Keep toolbar Preferences as a discoverable secondary entry.
- Add resizable sidebar width with persisted setting and sensible min/max widths.
- Ensure sidebar resizing does not conflict with pane splitter resizing.

**Acceptance checks**

- CoFinder menu contains Preferences and opens the same Preferences surface.
- Sidebar drag resizes smoothly and persists across relaunch.
- File panes remain usable at min sidebar width and normal window sizes.

## Test Strategy

- **Unit tests:** path validation, rsync arg/target generation, text sniffing, directory count helpers, settings migration, active-pane/toolbar state helpers.
- **Service tests:** local/remote create/delete operations using mocked fs/SFTP clients.
- **Integration-style tests:** transfer queue enqueue paths with Unicode and directory upload semantics.
- **Manual smoke:** real SFTP/rsync tests only inside isolated roots, including `/mnt/gpfs1/Users/zhouwenxiong/CoFinder_test` on `sge` when available.
- **Regression gates:** `npm test`, `npm run typecheck`, `npm run build`, `npm run check:secrets`, `npm run dev`.

## Risk Notes

- Unicode transfer support must not become shell injection support. Prefer structured argument arrays and narrow rejection of only control/shell-dangerous cases.
- Remote recursive delete is destructive; confirmation and deterministic errors are mandatory.
- Inspector async directory counts must stay capped/cancelable to avoid freezing on large remote trees.
- Path restore must not reconnect automatically using saved credentials unless a later milestone explicitly adopts session auto-reconnect.

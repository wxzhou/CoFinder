# CoFinder V1.5 Plan — Drag-and-Drop Transfer & Selection

## Metadata

| Field | Value |
| --- | --- |
| **Product milestone** | V1.5 |
| **Target release** | Originally planned as v0.6.0; included in v1.0.0 |
| **Status** | Implemented and included in **v1.0.0**; no standalone v0.6.0 tag |
| **Depends on** | **V1.4** conflict detection and resolution (mandatory foundation) |
| **Non-goals** | Cross-window tab drag; Finder-complete move semantics; remote edit auto-sync; parallel transfer queue |

## Goal

Add **direct manipulation** expected of a graphical file manager—drag transfers and marquee selection—without weakening safety.

## Scope / milestones

### M1 — Drag selected files between panes

**Status:** implemented.

- **Local → remote** → upload; **remote → local** → download.
- Multi-select and **directories** supported where technically feasible.
- Before drop: validate **target path**, **connection**, **tabId**, and enqueue through the same IPC as toolbar/context actions.

### M2 — Drop target feedback

**Status:** implemented.

- Highlight row/path when hovering a valid directory target.
- Drop on **empty pane area** = current directory (when defined product-wise).
- Invalid targets show **forbidden** affordance; **no silent failures**.

### M3 — Drag from Finder into app

**Status:** implemented for Finder → remote upload.

- Start with **minimal safe scope** (e.g. Finder → **remote** pane triggers upload only).
- Avoid fragile “move” semantics until explicitly specified.

### M4 — Marquee selection

**Status:** implemented.

- Begin drag only from **pane chrome/background**, not from row primary interaction targets.
- Compatible with **Cmd/Shift** modifiers per existing rules.
- Performance acceptable on large directories (throttle hit-testing if needed).

### M5 — Gesture conflict rules

**Status:** implemented and documented here.

Document and enforce priority:

1. **Splitter** drag highest priority.
2. **Row drag** starts **transfer** when movement exceeds threshold.
3. **Background drag** starts **marquee**.
4. **Single click** = select; **double click** = open / enter directory.

## Risk notes

- **High UX/regression risk**: mis-drag can cause wrong-direction transfers or wrong targets.
- Must reuse **V1.4 conflict** pipeline—no duplicate policy in renderer.
- Electron/HTML5 DnD quirks on macOS require careful testing in dev **and** packaged **`file://`** builds.

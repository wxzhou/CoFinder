# CoFinder V2.0 Plan — Stable Personal Release

## Metadata

| Field | Value |
| --- | --- |
| **Product milestone** | V2.0 |
| **Target release** | v1.0.0 |
| **Status** | Shipped as **v1.0.0** |
| **Depends on** | Successful execution of V1.3–V1.9 themes (or explicit scope cuts documented here and in CHANGELOG) |
| **Non-goals** | Cross-platform ports; IDE features; remote edit auto-sync; App Store; multi-user cloud sync; plugin ecosystem |

## Goal

Declare CoFinder **stable for personal use**: documented, tested, and behaviorally aligned across UI, transfers, preferences, packaging, and security—not perpetual prototype.

## Release criteria (milestones)

V2.0 is the **stable personal release**, not a requirement to complete every planned power-user feature. Items below are split into core release blockers and planned-but-cuttable scope; the cuts are explicit in `CHANGELOG.md`, `README.md`, and this file.

### M1 — Core UX complete

- V12 shell **default** and stable.
- **Keyboard shortcuts** complete per V1.3.
- **Pane splitter** complete.
- **Tab reorder** complete.
- **Local favorites** complete.
- **Remote favorites by profile** complete.
- **Limited read-only remote preview** for sniffed text/images complete and documented.

**Status:** shipped in v1.0.0. V12 is default; shortcuts, splitter, tab reorder, favorites, and limited read-only remote preview are implemented and covered in smoke docs.

### M2 — Transfer reliability complete

- **Conflict handling** (V1.4) done.
- Queue **retry / cancel / stop** semantics clear and documented.
- **Error taxonomy** in place.
- **Drag-and-drop transfer** (V1.5) done with conflict integration.
- **`docs/smoke-test.md`** covers primary transfer paths end-to-end.

**Status:** shipped in v1.0.0. V1.4/V1.5 smoke sections cover conflict-safe upload/download, retry, drag-and-drop, and queue controls.

### M3 — Preferences MVP complete

- General, transfer, and appearance preferences per V1.6.
- **Settings schema migration** path proven with at least one safe evolution.

**Status:** shipped in v1.0.0. Settings schema advanced from v1 to v2 for onboarding dismissal with unit coverage.

### M4 — Documentation complete

- **`README.md`** accurate vs behavior.
- **`CHANGELOG.md`** accurate per semver.
- **`docs/roadmap.md`** reflects shipped vs planned without stale claims.
- **`docs/smoke-test.md`** executable.
- **`docs/dev/PROJECT_CONTEXT.md`** matches codebase.
- **`docs/dev/ARCHITECTURE.md`** IPC list current.

**Status:** shipped in v1.0.0. V2.0 update refreshed README, CHANGELOG, roadmap, smoke/release/security docs, project context, and architecture IPC inventory.

### M5 — Packaging stable

- **dmg + zip** install and launch cleanly.
- **`file://`** renderer load verified post-build.
- App icon and **version/tag/release** alignment.
- `npm run check:secrets` passes in CI/local release prep.

**Status:** shipped in v1.0.0. Local signing is not configured; this must be disclosed for any public artifact.

### M6 — Security boundaries verified

- Profiles store **no plaintext passwords**.
- **`safeStorage`** credential path exercised.
- **rsync** never receives saved SFTP password.
- Remote preview cache is **read-only**, cleaned on disconnect/tab close/quit, and never syncs local cached edits back to remote.
- Renderer uses **preload/IPc only**—no Node escape.
- IPC remains **`{ ok, data }` / `{ ok, error }`** uniformly.
- Logs and diagnostics **do not leak** secrets.

**Status:** shipped in v1.0.0 by policy and tests. Manual smoke remains required before publishing or reissuing artifacts.

## Cuttable before v1.0.0 if explicitly deferred

- Full auto-update implementation.
- Remote chmod / advanced remote operations beyond the shipped baseline.
- Remote directory size cancellation and advanced symlink handling.
- Full Preferences UI beyond the MVP needed for stable defaults.

**V2.0 cuts:** full auto-update install is deferred; the shipped update path is manual GitHub Releases. App Store, remote edit auto-sync, cross-platform ports, plugin ecosystem, full ACL editor, and IDE-like workflows remain out of scope.

## Acceptance checks

- Full suite: `npm test`, `npm run typecheck`, `npm run build`, `npm run check:secrets`
- Full manual smoke per **`docs/smoke-test.md`** plus **`docs/release-checklist.md`**
- Optional: staged beta period or dogfood checklist before future stable releases.

## Documentation updates

- All docs in M4 above, plus **`docs/security.md`** review.
- GitHub Release notes mirroring **CHANGELOG** for v1.0.0.

## Risk notes

- **v1.0.0** raises user expectations for **stability** and **backward compatibility**—avoid last-minute large features.
- Documentation drift is a **release blocker** for this milestone.

# CoFinder V2.8.7 / v1.8.7 Plan

| Field | Value |
| --- | --- |
| Product milestone | V2.8.7 |
| Target release | v1.8.7 |
| Status | Complete on dev |

## Goal

Fix hands-on workflow regressions found after V12 toolbar polish without redesigning the UI.

## Scope

- Keep all current V12 layout and icon styling stable.
- Allow blank file-list space below rows to clear selection.
- Make New Folder select the default name on dialog open.
- Make New Text File use the same explicit naming dialog as New Folder.
- Detect stale SFTP sessions after sleep/idle disconnects and move the remote pane out of misleading Connected state.

## Non-Goals

- No toolbar redesign.
- No new transfer behavior.
- No remote auto-reconnect.
- No change to destructive-operation confirmation behavior.

## Acceptance

- Local and remote file-list blank space below rows clears selection.
- Local and remote New Folder dialogs focus and select `New Folder`.
- Local and remote New Text File dialogs request a name before creation.
- Remote list/open failures caused by stale SFTP connections surface as disconnected/reconnect-required state.
- Tests and build pass.

## Verification

- `npm run typecheck`
- `npm run build`
- `npm test`
- Relevant smoke checks in `docs/smoke-test.md` under V2.8.7.

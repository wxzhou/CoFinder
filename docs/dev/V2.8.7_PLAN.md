# CoFinder V2.8.7 / v1.8.7 Plan

| Field | Value |
| --- | --- |
| Product milestone | V2.8.7 |
| Target release | v1.8.7 |
| Status | Complete on dev |

## Goal

Fix hands-on workflow regressions found after V12 toolbar polish without redesigning the UI, then address follow-up reliability feedback in the same v1.8.7 line.

## Scope

- Keep all current V12 layout and icon styling stable.
- Allow blank file-list space below rows to clear selection.
- Make New Folder select the default name on dialog open.
- Make New Text File use the same explicit naming dialog as New Folder.
- Detect stale SFTP sessions after sleep/idle disconnects and move the remote pane out of misleading Connected state.
- Unify file-list and Inspector kind/type terminology as `Kind`; keep Owner visible in Inspector.
- Reuse the same read-only remote preview cache path for a remote file within a session, even after remote updates.
- Improve perceived remote listing responsiveness by caching owner-name lookups, bounding slow owner resolution, and showing initial remote listing as loading rather than empty.
- Add an optional remote pane auto-refresh preference, off by default with a 60-second default interval.
- Simplify transfer drawer chrome and add folder-upload child file progress details.
- Keep remote Owner display aligned between file list and Inspector.
- Keep remote auto-refresh preference controls visually grouped and disabled state obvious.

## Non-Goals

- No toolbar redesign.
- No remote download folder pre-scan in this patch; folder child progress is implemented for local folder uploads.
- No remote auto-reconnect.
- No change to destructive-operation confirmation behavior.

## Acceptance

- Local and remote file-list blank space below rows clears selection.
- Local and remote New Folder dialogs focus and select `New Folder`.
- Local and remote New Text File dialogs request a name before creation.
- Remote list/open failures caused by stale SFTP connections surface as disconnected/reconnect-required state.
- Inspector uses `Kind` and displays Owner or `—`.
- Remote preview cache path is stable for the same tab/connection/path session key when the remote file changes.
- Preferences exposes disabled-by-default remote auto-refresh with a numeric interval.
- Remote initial list shows loading rather than an empty-folder state.
- Local folder uploads show current child file and completed/total file count in Transfers.
- Expanded transfer drawer no longer repeats the same active/queued summary already shown in the collapsed bar.
- Remote Owner column and Inspector Owner prefer resolved usernames and do not cache unresolved UID fallbacks.
- Transfer drawer top controls are consolidated into a single row, and folder upload summaries distinguish folder file-count progress from current-file byte progress.
- Tests and build pass.

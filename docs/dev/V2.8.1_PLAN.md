# CoFinder V2.8.1 Plan — Pane-Scoped Toolbar Cleanup

| Field | Value |
| --- | --- |
| **Product milestone** | V2.8.1 |
| **Target release** | v1.8.1 |
| **Branch** | dev |
| **Scope type** | UI patch release after V2.8 / v1.8.0 |
| **Primary goal** | Remove the redundant global toolbar and make local/remote pane actions explicit, one-row, and pane-scoped. |

## Context

V2.8 completed remote Quick Look, but the V12 interface still exposes a global toolbar above the two-pane workspace. Some actions in that global toolbar depend on whichever pane is currently active, while equivalent pane-scoped actions already exist lower in each pane.

Observed issues:

- Disconnect appears in multiple places.
- Copy current path appears both globally and inside each pane.
- The pane header has several rows and large unused areas.
- Preferences lives in the global toolbar even though it is application-level, not pane-level.

V2.8.1 is a patch-style milestone to consolidate this layout before starting larger V2.9 work.

## Milestones

### M1 — Plan and Version Scope

Status: Implemented.

Acceptance:

- Add this plan under `docs/dev`.
- Treat this release as **v1.8.1**, not v1.9.0.
- Keep the change limited to V12 shell/layout behavior and related documentation.

### M2 — Remove Global Toolbar

Status: Implemented.

Acceptance:

- V12 shell no longer renders the top global toolbar.
- Global active-pane-dependent controls are not present in the main header.
- Existing tab strip, pane split, transfer drawer, and legacy V11 shell remain intact.

### M3 — Add One-Row Pane Toolbars

Status: Implemented.

Acceptance:

- Local pane toolbar, in one row, contains:
  Back, Forward, Enclosing folder, Home, Refresh, Toggle Inspector, Upload, New folder, New text file, Delete, Open terminal here, Filter names, Recent, History, Clear Recent.
- Remote pane toolbar, in one row, contains:
  Back, Forward, Enclosing folder, Home, Refresh, Toggle Inspector, Download, Edit remote text file, New folder, New text file, Delete, Open terminal here, Disconnect, Filter names, Recent, History, Clear Recent.
- Toolbar actions operate on their own pane without depending on active-pane state.
- Copy current path remains on the breadcrumb row, once per pane.

### M4 — Sidebar Preferences and Remote Status Placement

Status: Implemented.

Acceptance:

- Preferences moves to the lower-left of the V12 sidebar.
- The remote pane header no longer has a right-side Disconnect link.
- Connected/offline/connecting/error status is displayed beside the remote pane title.

### M5 — Documentation and Verification

Status: Implemented.

Acceptance:

- Update README / roadmap / changelog / smoke-test notes for v1.8.1.
- Run automated tests and build.
- Record smoke coverage for the toolbar consolidation.

## Non-Goals

- No new file operation behavior.
- No transfer queue, remote edit, remote Quick Look, or column-view changes.
- No legacy V11 UI redesign.
- No new IPC channels.

# CoFinder V2.8.3 Plan — Inspector Detail and Keyboard Selection Fixes

| Field | Value |
| --- | --- |
| **Product milestone** | V2.8.3 |
| **Target release** | v1.8.3 |
| **Branch** | dev |
| **Scope type** | Bugfix patch after V2.8.2 / v1.8.2 |
| **Primary goal** | Restore folder size details, make list selection easier to clear, and add Finder-like keyboard row selection without changing existing page navigation shortcuts. |

## Context

Hands-on v1.8.2 testing found six interaction and polish issues:

1. Folder Inspector no longer displays folder size.
2. Once a file is selected, clearing the selection is awkward when the list fills the pane.
3. Plain `Up` / `Down` scroll the page instead of moving row selection.
4. `Shift+Up` / `Shift+Down` do not extend the current selection.
5. Inspector preview icons are wrapped in an unnecessary rounded square and are too small.
6. Document icons need softer rounded corners, including the folded corner.

## Milestones

### M1 — Document the Patch

Status: Implemented.

Acceptance:

- Add this V2.8.3 plan before code changes.
- Keep the scope narrow: no transfer, remote edit, Quick Look, or large layout changes.

### M2 — Restore Inspector Folder Details

Status: Implemented.

Acceptance:

- Inspector single-folder metadata shows folder size instead of `—`.
- Local and remote Inspector fetches request directory size/count details for selected folders.
- Existing file metadata behavior remains unchanged.

### M3 — Improve List Selection Interaction

Status: Implemented.

Acceptance:

- Selected row highlight is limited to the Name column.
- Clicking Date modified, Size, Kind, or list blank space clears selection.
- `Cmd`-click on a selected Name cell still toggles that row off.
- Plain `Up` / `Down` move selection to the previous/next visible row.
- `Shift+Up` / `Shift+Down` extends or shrinks a contiguous range from the selection anchor.
- Existing `Cmd+Up` / `Cmd+Down` and `Option+Up` / `Option+Down` page navigation behavior is preserved.

### M4 — Polish Inspector and File Icons

Status: Implemented.

Acceptance:

- Inspector preview icons no longer sit inside a rounded square wrapper.
- Inspector preview icons are visually larger.
- Document icons use rounded outer corners and a rounded folded corner.

### M5 — Version, Docs, and Verification

Status: Implemented.

Acceptance:

- Bump `package.json` and lockfile to `1.8.3`.
- Update README, CHANGELOG, roadmap, and smoke-test notes for v1.8.3.
- Run `npm test` and `npm run build`.

## Non-Goals

- No changes to transfer scheduling, remote editing, Quick Look cache behavior, or release packaging.
- No change to existing `Cmd+Up` / `Cmd+Down` or `Option+Up` / `Option+Down` navigation shortcuts.

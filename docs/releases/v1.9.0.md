# CoFinder v1.9.0 — Stable Daily-Use Rollup

CoFinder v1.9.0 rolls up the stability, remote-edit, Jobs pane, file-operation, and V12 UI polish work completed since v1.8.0. This is intended as the next stable personal macOS build.

## Highlights Since v1.8.0

- Removed the active-pane-dependent global toolbar and moved commands into local/remote pane-owned toolbars.
- Improved selection, keyboard navigation, Inspector toggling, file-list columns, tab chrome, sticky headers, and toolbar icon polish.
- Unified remote `Open` and `Edit` around writable app-managed local-copy sessions with save-back and conflict checks.
- Removed the misleading separate remote `Quick Look` context action; double-click, Space, and remote `Open` now use the local-copy model.
- Added a unified Jobs pane for upload, download, delete, compress/decompress, and MD5 work.
- Added SFTP fallback for upload/download when rsync cannot authenticate non-interactively on password-only sites.
- Made remote deletion of large/deep folders more reliable with a server-side delete path.
- Expanded `File Operation` with Touch, Change Timestamp, file/folder Compress, Decompress, Generate MD5, and remote Change Permissions.
- Added tabbed Preferences, remote auto-refresh/reconnect controls, paired local/remote path restore, and a fixed titlebar sidebar toggle.
- Fixed several hands-on UI issues, including the Change Timestamp dialog field overflow.

## Notes

- macOS only.
- Artifacts from local builds may be unsigned and not notarized.
- Remote transfers still prefer rsync over SSH when passwordless/non-interactive SSH works; password-authenticated sites fall back to the active SFTP connection.
- Future work such as remote copy/move, multi-lane parallel Jobs, grep/less content tools, and true read-only remote Quick Look remains deferred.
